- 只收录 **官方来源**：国家法律法规数据库（flk.npc.gov.cn）、中国人大网（npc.gov.cn）、中国政府网（gov.cn 及其政府子域名）、最高人民法院（court.gov.cn / gongbao.court.gov.cn）、人力资源和社会保障部（mohrss.gov.cn）、以及经逐域核验的**省级法院官网**（广东/上海/江苏/河南/江西/辽宁/天津/河北 + 广西）与省级人社厅/政府网（gov.cn）；
- Phase 7B 起按“官方发布批次”收录劳动人事争议典型案例：最高法/人社部联合批次、最高法指导性案例、最高法各类劳动类典型案例、省高院/人社厅联合发布的典型案例等；每批记录 官方URL/发布机关/发布日期/案例数/核验日期/地区；
- **不**采集百科、博客、律所文章、公众号、商业法律数据库、新闻转载站（网易/搜狐/澎湃等）、抖音、小红书；官方公众号仅作发现线索，不能核验 URL 的不得入库；
- 法条与案例文本均取自官方现行页面，未从模型记忆补全；页面未公布案号 → documentNumber=null；无法核实的字段如实标注；案例为结构化概括或页面原文节选，**不整篇复制裁判文书**。
